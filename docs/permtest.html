Permutation Test

Author

Elene Barbakadze

Published

October 28, 2025

The dataset, Students Data Analysis, contains information on students’ graduation acceptances (did not get into the graduate school, got into a local graduate school, got into a international graduate school) and their assigned class (class), a categorical variable with two groups. Students were initially divided into two classes, but instructors suspected that students in one class might be performing significantly differently from those in the other.

To test this hypothesis, I will use a permutation test to compare acceptance rates between the two classes. The procedure involved repeatedly shuffling the class labels while keeping the graduation scores fixed, then calculating the mean difference in graduation rates for each permutation. This generated a null distribution representing the differences we would expect if class assignment had no real effect on performance.

IMPORTANT NOTE: The dataset used in this analysis is half-synthetic, meaning that although it was originally based on student records, the variables have been anonymized, censored, and partially generated to protect privacy. As a result, the class categories do not represent real student groups, and the patterns observed in the data may not reflect any real-world population. The analysis here should therefore be interpreted purely as a practice exercise for understanding and applying permutation tests.

Hypotheses

Null hypothesis (H₀): There is no difference in graduate school acceptance rates between the two classes. Any observed difference is due to random chance.

Alternative hypothesis (Hₐ): There is a difference in graduate school acceptance rates between the two classes.

Step 2: Permutation Test Function

This function tests whether the difference in the proportion of students accepted to graduate school between the two classes could have occurred by chance alone. Because grad is coded as 0 or 1, the average within each class represents the proportion accepted. The test works by shuffling the grad values across students, recalculating the difference in acceptance proportions for each permutation, and comparing those values to the observed difference. This produces both the observed statistic (ave_diff) and a distribution of permuted statistics (perm_diff). I set a random seed to ensure reproducibility and used map() to repeat the permutation process 1,000 times, storing all results in a data frame called perm_stats.

Show code 
#a function that computes the observed and permuted differences
grad_diff <- function(rep, students_clean) {
  students_clean |> 
    # shuffle grad values
    mutate(grad_perm = sample(grad, replace = FALSE)) |> 
    group_by(class) |> 
    summarize(
       # observed proportion
      obs_ave = mean(grad),
      # permuted proportion
      perm_ave = mean(grad_perm)) |> 
    summarize(
      # observed difference
      ave_diff =diff(obs_ave), 
      # permuted difference
      perm_diff = diff(perm_ave), 
      # iterate label
      rep = rep)
}

# Run the permutation test 1000 times
set.seed(47)
number <- 1000
perm_stats<- map(c(1:number), grad_diff, students_clean) |> 
  list_rbind()

From the plot, we can see that the red line, which represents the observed difference, is slightly to one side of the null distribution. However, it does not seem far enough from the center to suggest a meaningful or statistically significant difference at first glance.

Step 4: Calculate the p-value

Finally, I calculated the p-value

Show code 
# Compute the two-sided p-value:
perm_stats |> 
  summarize(p_val_ave = mean(abs(perm_diff) >= abs(ave_diff))) |>
  gt() |> 
  tab_header(
    title = "Left-tailed p-value"
  )
Left-tailed p-value
p_val_ave
0.285

Because this is a two-sided test, the p-value was computed as the proportion of permuted differences whose absolute value was greater than or equal to the absolute observed difference.

Step 5: Results

The permutation test produced a p-value greater than 0.05, meaning the observed difference in graduate school acceptance proportions between the two classes is not statistically significant. In other words, the difference we see could easily have arisen by random chance, so we fail to reject the null hypothesis (H₀). Based on this analysis, there isn’t enough evidence to conclude that class assignment meaningfully affects graduate school acceptance within this dataset.
